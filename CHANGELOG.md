# Changelog

All notable changes to Owlink. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and Owlink uses [semantic versioning](https://semver.org/). Each release's notes on GitHub
are its section below (`Scripts/changelog-section.sh`).

## [Unreleased]

### Fixed
- **A long line with emoji or accents no longer hangs the editor.** In large-document mode, a line over 20,000 characters is shown in pieces. If an emoji, a flag, an accented letter or another character made of several parts fell where one piece ended, Owlink could stop responding while laying the line out. Every piece now starts after the one before.
- **Switching built-in models during a load no longer leaves a model in memory.** If you asked Cedric with one built-in model while another was still loading, both loads ran at once. The first model could stay in memory, unused, until you quit, and a load that hung could be forgotten while it still ran. Owlink now loads one model at a time: the second waits for the first, then the first is unloaded. If the first load hung, Cedric says the model is still loading, as he does for the same model.
- **Quit no longer hangs after a model load that didn't finish.** If the built-in model's first run never returned (a graphics card that hung), Owlink set the model aside after 60 seconds, but quitting then waited for it forever. Quit now waits a few seconds at most.
- **A stale “Looks like JSON” hint no longer offers to format the file.** Showing that hint again from “Recent hints” after the text had changed offered Fix it, which reformatted the whole file. Now it shows the title and detail only, like any hint whose text has changed.
- **Saving through a symbolic link checks the file it writes.** If the link, or a link to a folder on the way to the file, was pointed somewhere else during a save, Owlink could check one file and then replace another, read-only one. Owlink now finds the file and its folder once, and checks and writes the file in that folder. A writable file in a folder you can't list still saves, and so does a file you can read and write in a folder that doesn't allow new files. In a folder that doesn't allow new files, Owlink writes over the file it checked, through the same folder. If that file was swapped for another one during the save, the save fails with an error and the other file isn't changed.
- **A full disk no longer empties a file saved in a folder that doesn't allow new files.** Owlink saves such a file by writing over it, and it emptied the file first. If the disk filled up (or a quota or file-size limit was reached) during the save, the file was left empty or holding only the start of your text. Owlink now refuses the save before writing when the disk has less free space than the whole new text, or the text is over the file-size limit. Before writing, it copies the file to a private temporary folder; if writing fails, it puts the file back from that copy. If putting it back fails too, the message says where the copy is. You see the same “out of space” or “couldn't save” message, and your text stays in the tab. Another app writing the same file during the save can still lose its changes.
- **A file opened through a symbolic link notices changes by other apps.** Owlink checked the link itself instead of the file it points to. If another app changed that file, Owlink didn't show “Changed on disk”, didn't reload a tab with no edits, and ⌘S wrote over the other app's changes without asking. The same happened if the link was pointed at a different file while the tab was open. Owlink now checks the file a save would write. If the link points nowhere any more, the file counts as missing. Owlink also notes which file it read or saved, so another file put in its place counts as a change even with the same date and size: a link pointed at a copy that kept the original's date, or another app replacing the file with one of the same size in the same second.
- **A cut-off UTF-16 file no longer loses its last byte when saved.** A file with a UTF-16 byte order mark and an odd number of bytes (from a download that stopped part way, for example) opened with no notice, and ⌘S dropped its last byte. Owlink now says the file isn't text in a supported encoding, as it does for other broken UTF-16, and doesn't change it. Find in Files and Replace in Files skip it. Follow File on a UTF-16 log caught half way through a character shows the whole characters and finishes that one when the rest arrives, instead of showing garbled text after it.
- **Cedric's proposed edits are checked again after a language change.** An edit proposed while the tab was Plain Text kept its “no problems” check after you switched the status bar to JSON, so Apply could break valid JSON. Changing the language now checks Cedric's open proposals again, and Apply stays off if a proposal doesn't parse.
- **A server reporting an absurd context size no longer crashes Owlink.** LM Studio or Ollama reporting a context window larger than any model's made Ask Cedric crash while working out how much text to send. Such a report now counts as the largest window, and Ask Cedric sends at most 32,000 characters' worth as before.
- **Preview images stay inside your folders.** In the preview, an image path that starts with `/` (as static site generators write it) no longer looks in the root of a disk under `/Volumes` or in a folder that holds your home folder. It searches the same folders as wiki-links. A folder opened in the sidebar is still searched.
- **Markdown, JSON and YAML files show their own icons when Owlink opens them by itself.** On a Mac where Owlink opens .md, .json and .yaml files without your choice (because nothing else names those types), Finder showed the generic text page for them instead of the MD, JSON and YAML icons. The same went for plain text, XML, HTML and CSS files Owlink opened without your choice. Each type now gets its icon from its own entry. Which app opens which file is the same as before. A .log file that opens in Owlink without your choice still shows the generic page until you choose Owlink for logs.
- **A comment with `import` inside a template string no longer relaxes Cedric's JavaScript check.** `` `${/* import */ 1}` `` made a JavaScript syntax error in an unrelated part of a proposed edit only a warning, as if the file might be a module. Comments inside `${ … }` no longer count.

## [0.5.3] - 2026-11-24

### Added
- **Load model at launch.** In Settings › Cedric, with the built-in engine: on, Owlink loads the model in the background when it starts, so automatic hints can use it right away. It never holds up opening a window, and the 60-second limit applies. Off by default.
- **Recent hints can be opened again.** Under “Recent hints” in Cedric’s popover, click an entry (or Tab to it and press Return or Space) to show that hint again in his bubble, with Fix it and Show Me if the text it was about is still there. If the text has changed, or the hint was about a file you have since closed, you still see its title and detail. VoiceOver reads each entry as a button with its time, title and detail.
- **A Preview toggle for CSV and TSV files.** CSV and TSV files get a Preview eye on the status bar, right beside the format picker (“CSV / TSV”), so you can show or hide the table without the View menu or ⌥⌘P. It turns on while the table is shown, docked or detached, and off when it's closed.
- **Cedric's proposed edits are checked before you can apply them.** The change is tried on a copy of the document first. If it breaks JSON, a property list, XML or JavaScript, leaves brackets unbalanced, or declares a JavaScript `const`/`let` from itself, Cedric is told once and asked to fix it; if it still fails, the card says “Doesn’t parse” (or “Won’t run”) with the reason and Apply stays off. Problems the document already had don't count against the edit: if it didn't parse before, the card only warns that the change may not parse, and Apply stays on.
- **Warnings on proposed edits.** A card notes when a change assigns a variable to itself, changes a Swift `let` it can't change in place, or adds or drops a negation in prose (“May change the meaning: adds ‘not’”). Apply stays on.

### Changed
- **The built-in engine's context fits your Mac's memory.** Each model gets a 16,384-token context when its weights and that context fit in half of your Mac's memory, else 8,192, and at least 4,096. On an 8 GB Mac that is 8,192 for the Qwen3 4B models and 4,096 for Qwen2.5 Coder 7B; 16 GB and up keep 16,384. How much of a file Ask Cedric sends is worked out from the same number.
- **Cedric doesn’t review large files on his own.** In a file over 100 KB or 2,000 lines, Cedric no longer checks with the AI on open, save or a pause in typing, and doesn’t pop up typo or grammar hints by himself, so a big log doesn’t start whole-file AI, typo or grammar work. His popover says auto-review is off for the file, with its size. Ask Cedric, Ask AI Now, Check Script for Risks and Check Grammar with Cedric still work: the first time you ask about such a file, Cedric names its size and asks you to confirm, with Cancel as the default. His rules hints, which only read the part of the file you are looking at, carry on. The limits are fixed: 100 KB covers almost any source file, note or Markdown document, and 2,000 lines catches dense logs that are smaller than that. Large-file mode (25 MB, or a line over 20,000 characters) is unchanged, and Turn On Anyway there doesn’t turn automatic review back on.
- **Asking Cedric to fix spelling opens Fix Typos.** “Fix the spelling mistakes”, “check spelling” and similar requests step through the system spell checker's suggestions on this Mac instead of asking the AI model to rewrite the text. Nothing is sent anywhere.
- **Cedric says what he proposes.** After proposing an edit, Cedric is told nothing is applied until you press Apply, so his answers describe the proposal instead of claiming the change was made.

### Fixed
- **Long questions to LM Studio and Ollama are no longer cut off silently.** Ask Cedric reads the context the server runs the model with (LM Studio's loaded context, Ollama's loaded context or `num_ctx`, else their 4,096-token default) and sends no more than fits, splitting a whole-file review into parts when needed. A server that doesn't say keeps the previous limit.
- **The preview accepts only the page it is loading.** A response for any other page in the preview, such as another document's or a blank page, is refused, also between loads.
- **Small document icons are no longer cut off.** In Finder's list view and other small sizes, Owlink's document icons (most visibly `.log`) no longer have the page's right edge, fold, top or bottom clipped. Every type now keeps a clear margin at 16, 32 and 64 pt, on Retina too.
- **Large text files no longer crash on open.** On macOS 26, opening a text file over about 25 MB (a 30 MB or 55 MB log, for example) made Owlink quit within a second. Large files of ordinary lines now open in large-document mode as before, without the crash, and pasting a very long line (over 20,000 characters) into one no longer crashes either. **Revert to Saved** and **Reload** now settle large-document mode from the whole file on disk.
- **Read-only files stay read-only.** A file you can't write (no write permission, such as `chmod 444`, locked in the Finder, or on a read-only volume) opens read-only, with “Read-Only” in the title and a bar that says why. ⌘S no longer replaces it silently: Owlink offers Save As instead. **Allow Editing** on the bar lets you type, but the file is still never saved over. Cedric's Apply is off for these files. If the file's permissions change while it is open, Owlink notices when you save or come back to the window.
- **Reloading a read-only file no longer loses unsaved edits.** If a file with unsaved edits became read-only and changed on disk, Reload (on the “Changed on disk” bar or from Cedric) and File › Revert to Saved left your edits in place but marked them as saved, so closing the tab could drop them without asking. Reload and Revert to Saved now replace the text with the file on disk, keep the tab read-only, and Undo brings your edits back. If the text can't be replaced, your edits stay unsaved and the bar stays.
- **Opening a file no longer loads the built-in model.** With the built-in engine and automatic checks on, Cedric used to load the model on his own about ten seconds after you opened a file, to look for hints. On one Mac that first load hung the graphics card and the whole screen froze until a forced restart. Now opening, saving, typing or leaving a file open never loads the built-in model. Automatic AI hints use it only after you have asked Cedric something since Owlink started (Ask Cedric, a review, Ask AI Now, Check Grammar with Cedric, Check Script for Risks or Test Connection), or if you turn on the new **Load model at launch** setting, which is off by default, and only while the model is still in memory. When Owlink unloads it after a few minutes unused, automatic hints never load it again; they go back to rules only until you ask Cedric again. Until then Cedric keeps giving his rules hints as usual, and his popover says automatic hints start after you ask. Apple Intelligence, LM Studio, Ollama and another Mac work as before.
- **A model that doesn’t finish loading is set aside.** If the built-in model is still loading after 60 seconds, Owlink stops waiting for it. Cedric says so in his speech bubble (no alert, nothing takes focus; OK dismisses it), and automatic AI turns off. Rules hints keep working. Owlink never starts a second load while the first is still running: if you ask in the meantime, Cedric says the model didn’t finish loading in time and you can try again in a little while, or restart Owlink. Once that first load has stopped, Ask Cedric or a review can try loading the model once more; if that works, automatic hints come back, otherwise restart Owlink to try again.
- **A new question no longer waits behind the last one.** If you left a long Ask Cedric answer running (a whole-file question, say) and asked something else, the new question could sit on “…” for many minutes while the built-in model kept working on the old one, and only quitting Owlink stopped it. Now asking again in the same panel (typing a question, a quick action such as Explain or Review, or Check for Risks) stops the answer that was running first, and nothing from it turns up under the new question. You don’t need to press Stop. Stop, and closing the panel, stop the built-in model straight away too, even while it is still reading a long prompt.
- **Waiting shows what is happening.** Until Cedric writes his first word, the panel says “Processing prompt…” with how many seconds have passed, instead of a bare “…”. While he writes, the Stop button shows the time too.
- **Edits are labelled as proposed until you apply them.** Each edit card says “Proposed, not applied” (and its note is worded as a proposal too), and the answer is followed by “Proposed 1 change, not applied” (or how many). If the model writes as though it had already made the change (“Fixed ‘definately’…”, “Changed line 22…”, “I updated…”), Owlink rewords it as a proposal (“Proposed fix: …”, “I propose updating…”). Nothing changes until you press Apply, which still says “Applied. ⌘Z undoes it.”
- **Detaching the preview focuses its window.** View › Detach Preview (⇧⌥⌘P) and the preview's Detach button bring the detached preview window to the front with the focus, for Markdown, CSV and TSV, HTML and the other preview types, instead of returning the focus to the editor. A detached preview restored with your session still leaves the focus where it was.

## [0.5.2] - 2026-11-23

### Security
- **Web links in the preview always ask first.** A plain click on a web link in the Markdown or HTML preview no longer loads the page inside the preview, where the JavaScript and Network settings did not apply. Clicked or ⌘-clicked, web links now open in your browser only after you confirm. The question names the site on its own line (a name in non-Latin look-alike letters is shown as its plain-ASCII form and flagged), points out a user name placed before the site to disguise it, and has Cancel as its default button. If you cancel a link while the page's JavaScript is on, that page can't ask again until it reloads. Redirects, refreshes, form submissions, frames and page scripts cannot load a web page in the preview either.
- **Linked documents in the preview load from their real location.** A document opened through a symbolic link takes its type and its folder for images and links from the file that was checked and read.

### Added
- **Unsaved edits are marked.** A dirty tab and its window title show a trailing •, and the close button keeps the usual macOS edited dot. The mark clears when you save, revert, or undo back to the last saved text.

### Changed
- **Reopen files from last session is on unless you turn it off in Owlink.** macOS's “Close windows when quitting an application” setting no longer turns it off. With it off, tabs with unsaved text (including untitled tabs) still reopen after a quit or closing the last window, instead of going to Reopen Closed Tab, where unsaved text is deleted after 30 days. A `-reopenFilesFromLastSession NO` launch argument now works.

### Fixed
- **Obsidian vault bounds.** A stray `.obsidian` folder in your home folder (or above it, or at a disk's root) no longer makes that whole folder the vault for wiki-links and embeds in the preview; the vault falls back to the document's folder. A note saved directly in your home folder no longer searches all of it for bare `[[names]]`. Open the folder in the sidebar to use it as a vault on purpose.
- **Plain text document icon.** `.txt` files now have their own teal page with a TXT label, instead of a dark navy page that looked like the generic document icon in Finder and in the window title. Finder's 64 pt icon size now shows each type's label too.

### Removed
- **Open in Browser** in the preview bar and View › Preview, which only applied to web pages shown in the preview.

## [0.5.1] - 2026-11-23

### Added
- **Folder sidebar actions menu.** An ellipsis in the sidebar header offers the context menu's folder actions, plus Refresh and Collapse All.
- **Browse in preview.** Follow Markdown, HTML and web links in the preview with Back, Forward and This Document; Open in Browser asks before opening a web page externally. ⌘-click keeps the external link prompt.
- **VoiceOver names.** Find and Replace, Ask Cedric’s scope and question fields, Go to Line, and the New File/Folder name field now have VoiceOver names.

### Changed
- **The last session comes back.** Settings › General › Reopen files from last session is on by default and follows macOS's “Close windows when quitting an application” setting until you change it. Closing the last window, or quitting, restores those open tabs and their saved window state on the next launch. Opening a file from Finder still restores the rest of the session and focuses that file. With the setting off, files do not reopen; unsaved text stays in File › Reopen Closed Tab.
- **Ask Cedric names its model and shows typing dots while it writes.** Whole-file answers are combined without part labels.
- **Whole-file context is larger for built-in and server models.** Qwen can review a whole file when it fits; Apple Intelligence remains at a 5,000-unit budget / 4,096-token window.
- **Finder document icons.** Type-coloured pages now show a white symbol, with a short file type label in larger views.

### Fixed
- **Preview JavaScript and network access reset.** JavaScript and network access in the preview turn off when the document changes on disk or you navigate to another document; Back and This Document no longer turn them on again for reloaded content.
- **Preview links to a heading.** Links to a heading in another document open at that heading in the preview.
- **The folder sidebar gives its room back.** Hiding or closing it expands the document to fill the window again.
- **Obsidian image names.** Bare image names in Markdown, embeds and HTML `<img>` tags resolve in the vault, including `Images/` and the configured `attachmentFolderPath`.
- **Settings and dialog copy.** Remaining settings units, the Go to Line placeholder, default-editor type checkboxes, and the Compare window title are localized.

## [0.5.0] - 2026-11-22

### Added
- **Folder sidebar actions.** Right-click to create files and folders, rename inline, or move to Trash after confirmation. Open tabs follow renames; trashed text stays unsaved in its tab.
- **Hidden files created or renamed in the folder sidebar are shown without turning on Show Hidden Files.**
- **Explain and Rewrite Selection.** Select text and use the Cedric menu, editor context menu, Markdown Context Bar, or ⌥⌘E / ⌥⇧⌘E. Explain works with any ready local engine; Rewrite requires a model that passes the existing tool gate and offers Apply / Skip edit cards. Engines run on this Mac or a configured private LAN server only.
- **Built-in model licences before download.** Download opens a confirmation with the full bundled licence text; non-commercial terms are flagged. Showing the text does not fetch a URL; the model download starts only after Confirm.
- **Automatic checks on servers.** Automatic checks (and automatic AI grammar) are off by default for LM Studio, Ollama and custom servers. The first time you enable them, Cedric explains that visible text goes to the named server on your local network, not the cloud. If they were already on for a server, they stay off until that notice is confirmed. Existing Intel defaults and on-device behavior are unchanged.

### Changed
- **Cedric document icons.** Files Owlink opens (all 19 document types) show a white page with Cedric and the file type on a label in Finder, drawn from the same pixel art at every size so they stay legible in icon and list views.
- **Chunked whole-file reviews.** Check for Risks, Find Problems, Explain and typed whole-document questions can review up to eight overlapping parts when the file does not fit; progress and any unreviewed lines are shown.
- **Ask Cedric's document scope.** With no selection, Whole document is the default even when it needs trimming. Cedric sends whole lines centred on the caret or selection, and the chip names the lines sent; Visible text remains a choice. Check for Risks no longer claims a complete review was partial.

### Fixed
- **Inline Rename selects the base name.** In the folder sidebar, Rename leaves the file extension unselected.
- **The folder sidebar follows viewer tabs.** Opening a PDF, image, Office file or certificate from the tree keeps the sidebar beside it.
- **No AI hint on an empty document.** Cedric no longer asks Apple Intelligence, the built-in model or a local server for a hint when the document is empty or has fewer than 20 characters of text (spaces don't count). A new blank Plain Text document was being told it had an "Empty code block".

## [0.4.1] - 2026-11-21

### Added
- **Daily word target.** The stats popover (click the status bar's word count, or View › Show Statistics) has a second ring beside the file's word goal: how many words you write today, across every document. It counts the net words added since a document was last noted — on save, when the tab closes, and when typing pauses — never on each keystroke. Deleting text takes those words back, and the day never goes below zero. It resets at local midnight. The target is off until you type a number (empty clears it). The target and the count stay on this Mac, never in the file. Opening a file does not count the words already in it.
- **Float on Top.** Window › Float on Top keeps that window above other windows. It is per window, remembered with the session, and shows a checkmark while on. Sheets and the command palette still appear above the window.
- **Prose font.** Settings › Writing › Use a prose font for Markdown and plain text (off by default, so nothing changes until you turn it on) sets Markdown and plain-text tabs in a font of their own: the system font (SF Pro) by default, New York, or any installed family, at its own size (15 pt by default). Code tabs keep the monospaced font, a tab switches font when its language changes, and zoom scales both fonts alike; a large document (large-document mode) stays monospaced, for typing speed. Line numbers, folding, Readable Width (which counts a proportional font's average letter), Typewriter Scrolling and Focus work the same. Ln, Col still counts characters; ⌥-drag selects the rectangle you drag, by position; Add Caret Above / Below keeps the character column, which need not line up in a proportional font.
- **Ask Cedric proposes edits as cards.** A model trusted with tools (the built-in Qwen3 4B; not Apple Intelligence, which stays below the 80% bar) proposes each change as the exact text to find and its replacement, up to five per answer. Each comes back as a card with its reason, the before and after, and Apply / Skip; Apply is one undo step and works only while that text is in the document exactly once, so typing elsewhere doesn't spoil it, and a card whose text changed or became ambiguous says "Text changed or isn't unique; ask again". A read-only document never applies. Cedric only offers to edit when you ask for a change ("rewrite", "fix", "shorten", "rephrase", "correct"…), not when you ask whether something is right. VoiceOver reads each card's reason and change. The tool eval has 58 prompts (was 50): four asking for edits in other words and four questions with an edit word that should just be answered; Qwen3 4B scores 87.9% (51/58; the same 44 of the 50 older prompts as before).

- **The docked preview comes back.** A Markdown tab whose preview was docked when you quit (or closed the window) reopens with it docked, at the width you left it, once the first frame is up; it is remembered per tab with the session, so a tab without one stays without.
### Fixed
- **Context Bar clicks did nothing.** The Markdown buttons were refreshed while the window was still being built, before it was the current tab, so they stayed disabled and a click never ran the command. They enable once the tab is current. A click still works while the docked preview has the keyboard.
- **Ask Cedric's coverage note** ("I can see lines 1–12 of N") is left off when the question isn't about the document: a sum or a translation no longer gets it.
- **Copy as Rich Text** builds the folder's note-name index off the main thread, so the first copy in a large vault no longer pauses, and a copy that finishes late will not overwrite something you copied since.
- **Style Check and Cedric's hints skip logs.** A file of timestamped log lines (a leading timestamp and a log marker, including unified-log and syslog NOTICE or CRIT lines) is no longer checked as prose.
- **Settings:** an invalid server address no longer stops you turning AI off; changing the AI interval or automatic checks no longer rebuilds the provider; a change there selects Rules + AI only when AI turns on; Font size and Readable Width are no longer overwritten while you edit them; VoiceOver names the built-in model list and each model's Download or Delete.
- **Printing with line numbers** sizes the number column by the widest digit of the prose font.

### Changed
- **Readable Width is off until you turn it on.** It was on by default for Markdown and plain text, which left the line numbers at the window edge and a wide empty gap before the centred text. It is now off for every language. View › Readable Width still switches the current tab and keeps that choice. Settings › Writing › Readable Width (unchecked) is the default for tabs that have not chosen. With it on, the line numbers, fold triangles and git bars sit just to the left of the text column.
- **A Text menu.** Between Edit and View, as BBEdit's Text and Xcode's Editor menus: Selection, Line (with Comment Selection), Bookmarks, Text Tools, Indentation (was in Format) and Folding (was in View), out of an Edit menu of 22 entries. Compare With…, Compare with Last Commit and Next / Previous Difference move from View to File › Compare, and Follow File from View to File. Every shortcut is unchanged, and the command palette lists each command under its new menu.
- **Settings has tabs and applies at once.** Owlink › Settings… (⌘,) is one window with toolbar tabs: General (theme, font, quit on last close, Default editor for…), Editor (default indentation, Wrap lines, Show invisibles, Show line numbers, Highlight occurrences, Auto-close brackets and quotes, git changes in the gutter), Writing (readable width, spelling while typing, grammar in prose, Style Check) and Cedric (Show Cedric, Ask Cedric, Style tips in code, and the AI settings). Every control applies the moment it changes, with no Save or Cancel; text fields apply on Return or when you leave them. The View and Edit menu toggles are checkboxes there too, bound to the same settings, so a change in either place shows in both. The separate Cedric AI window is gone: Cedric › Cedric AI Settings… opens the Cedric tab, where Test Connection and each built-in model's Download, Pause and Delete stay buttons. Settings reopens on the tab you last used, names every tab and control for VoiceOver, and is still built only when first opened (each tab when first shown), never at launch.

### Known issues
- Exported HTML keeps site-root image paths (`/images/…`) as written; the preview and PDF export find them on disk, an HTML file opened elsewhere may not.
- With the built-in Qwen3 4B model, Ask Cedric still sometimes says the document doesn't mention something without looking it up first.
- Edit cards need a model trusted with tools (the built-in Qwen3 4B); Apple Intelligence answers in prose.

## [0.4.0] - 2026-11-21

### Added
- **Keyboard and VoiceOver polish.** View › Show Statistics opens the word-count popover from the keyboard and the command palette; with Full Keyboard Access the word count takes focus (Space or Return opens it). The status bar's Language, Text Encoding and Line Endings pop-ups have VoiceOver names and tooltips. The find bar's previous/next buttons are chevron symbols named Find Previous and Find Next.
- **Command palette.** View › Command Palette… (⇧⌘P) lists every menu command, Text Tool and Markdown command, with its menu path and shortcut, in every kind of tab. Type to narrow it: the letters only need to come in order ("md bold"), and a run of letters or the start of a word ranks higher. ↑/↓ and Return run the selected command, Esc closes. Commands you ran from it lately come first. Commands that can't run in the tab are shown dimmed, not hidden. The list is read from the live menus each time it opens (a median of about 17 ms on an M4 Pro, and under 20 ms with 500 commands), so new commands are in it automatically; nothing is built until it is first opened. VoiceOver reads the number of matches and the selected command.
- **Open Quickly.** File › Open Quickly… (⌥⌘O) opens the command palette for files: with a folder open in the sidebar, type part of a name and its files are listed by fuzzy match, name matches and word starts first ("fs" finds FolderSidebar.swift), or type a `/` to match the path. Return opens the file. Hidden files follow the sidebar's Show Hidden Files, and what `.gitignore` ignores is left out. The index is built in the background the first time it is used in a folder (up to 20,000 files) and kept current by the sidebar's folder watcher, one changed folder at a time. The current Markdown document's headings are listed too; start with `#` for headings only (Return jumps there) or `>` for commands, in either palette.
- **Context Bar.** One thin row of buttons above the text, for Markdown (the only file type with a set so far; code, plain text and other types get no bar and no empty row). It is on by default: View › Hide Context Bar puts it away and Owlink remembers that, View › Show Context Bar brings it back, and while it is hidden (or the file type has no set) no part of it is built. The Markdown set: a heading pull-down (Body, Heading 1–3), Bold, Italic, Strikethrough, Inline Code, Link, Bulleted List, Numbered List, Checkbox, Quote, Code Block, Insert Table, Image Link, and a preview toggle (an eye). - **An AI server on your network named over https is checked after each request too.** If the connection went to a public address (a DNS answer that changed after Owlink's check), the answer is thrown away and you see an error. Preview Replace… lists every change as before → after, with a box per file and per match to leave some out, and the files it skips and why (binary, over 20 MB, mixed line endings, changed since the search…). Edit › Undo Replace in Files puts the last replace back byte for byte, skipping any file edited since. Find in Files results are now grouped by file, and a **Respect .gitignore** box (on by default) skips what the folder's .gitignore files ignore.
- **Folder sidebar.** File › Open Folder… (⇧⌘O), or a folder dropped on the Dock icon or a window, shows the folder as an expandable tree at the left of the editor; View › Show Folder Sidebar (⌃⌘1) hides and shows it. Hidden by default: nothing is loaded or watched until a folder is opened. Folders list only when expanded, folders first in Finder order, without `.git`, `.DS_Store` or hidden files (Show Hidden Files in the context menu). What the folder's .gitignore files ignore is dimmed. A click opens the file in a tab, or selects its tab if it is open. The tree follows files created, deleted and renamed on disk. Context menu: Reveal in Finder, Copy Path, Find in Folder…, Close Folder. The folder, its expanded folders and the sidebar's width come back with the session.
- **Multiple carets and column selection.** ⌥-drag selects a column (dragging straight down makes a column of carets); ⌘-click adds or removes a caret; Edit › Selection › Add Caret Above / Below (⌃⇧↑ / ⌃⇧↓), Add Next Occurrence (⌘D: the word at the caret first, then each next match) and Select All Occurrences (⌃⌘G); ⎋ goes back to one caret. Typing, Delete, Return (with indent), Tab, auto-closed brackets and quotes, paste (one line per caret when the clipboard has as many lines), copy, cut, the arrow keys and ⇧-arrows work at every caret. Input methods and dead keys compose at the main caret and the committed text goes in at all of them. One ⌘Z undoes one edit at all carets and puts the carets back.

### Known gaps
- Code folding and split view come in 0.3.0.
- Replace in Files skips files with mixed line endings (open them to replace there), symbolic links, hard-linked files, read-only files ("read-only"), anything inside a `.git` folder or a `.git` file (whatever the Exclude field says), and files whose encoding was guessed as Latin-1, Windows-1252 or Mac Roman when the replacement has non-ASCII text or the file holds UTF-8 sequences ("encoding uncertain": it may be UTF-8 with a stray byte; open it to replace there). Undo Replace in Files leaves a file that has become read-only and says so; Undo stays available to try again once it can be written. Respect .gitignore doesn't read git's `core.excludesFile` and matches case-sensitively.
- Multiple carets: VoiceOver follows the main caret only; the extra carets don't blink; ↑/↓ and Add Caret Above/Below move by logical lines, not wrapped rows; each typed key at several carets is its own undo step.

Only the first 20,000 lines are scanned, and a longer script says so. With an AI engine, Cedric then explains each finding and ends with a verdict: "No obvious red flags (not a guarantee)", "Run only if you trust the source" or "Don't run it". Cedric never claims a script is safe: the app rewrites any line that does, even for a moment while the answer streams, and forces "Don't run it — review the flagged lines" after a high-risk finding or a partial review, whatever the model said. The script's own text is passed as data and can't talk the model into a verdict; without an engine, the panel says it is the scan only.

- **AI grammar check** in the owl's menu, using Ask Cedric's engine. The macOS spelling and grammar checker stays on.
- **The owl uses tools with the built-in Qwen3 model** (it scored 0.90 on Cedric's tool test after a prompt rewrite). Apple Intelligence and Qwen2.5-Coder stay without tools.
- More owl animations; idle CPU with the owl visible stays about the same.

### Changed
- **Ask Cedric is on by default when a local AI engine is ready** (Apple Intelligence, the downloaded built-in model, or a local server you set up and turned on), and works even when automatic AI hints are off; a network server is still used only when AI is on. Your choice sticks once you change it. Clicking the owl offers "Ask about this file…" first, or "Set Up Ask Cedric…" when there is no engine, and a one-time owl bubble points it out.
- **Long AI answers are no longer cut off.** The 120-second limit now covers only the wait for the first word; after that an answer may stream as long as words keep coming (30 seconds between them at most, 15 minutes in all).
- **Closing the last tab no longer brings it back.** Closing the last document tab or window still quits OwlInk, but it is now a close like any other: the tab goes to File › Reopen Closed Tab (⇧⌘T) with any unsaved text kept, and the next launch opens an empty Untitled tab. Quit (⌘Q) still restores every open tab.

### Security
- **No AI through the environment.** The test switches that turned Ask Cedric on for one run (`CEDRIC_ASK_ENGINE`, `CEDRIC_AI_FAKE`) work only in debug builds; a release build always waits for your opt-in.
- **Honest privacy wording.** The owl's Ask Cedric bubble, the Ask Cedric setting's tooltip and the owl's own instructions now say where text goes for the engine in use: on this Mac (built-in, Apple Intelligence), or to the AI server you set up (named), and that automatic AI grammar, when on, also sends prose after you pause typing.
- **Owner-only Cedric folder.** `~/Library/Application Support/Cedric` (CLI token, session buffers, models) and the folders made in it are created 0700, and tightened to 0700 if an older version left them wider. The CLI token stays 0600.
- **CLI token made atomically.** The `cedric` script writes a new token to a private temp file and hard-links it into place (a token already there is kept), and retries an empty read once after 50 ms, so a run racing the app never sends an empty token.

## [0.1.0]

The first release: a fast, simple, native text editor for macOS 14 Sonoma and later, in the
spirit of Notepad++. Universal (Apple silicon and Intel), signed with Developer ID and notarized.

### Changed
- **Built-in AI default is now Qwen3 4B Instruct (2507), Apache-2.0.** It replaces Qwen2.5 Coder 3B, whose Qwen Research License is non-commercial; that model stays an optional download labelled "Non-commercial licence", and anyone who already downloaded it keeps using it until the new default is downloaded.

### Added
- **Tabs that come back.** Native window tabs. Quitting never asks to save: every tab, untitled ones and unsaved changes included, is restored on the next launch. Unsaved text is autosaved about 1.5 seconds after you stop typing, so a crash or power cut loses at most that. Closing a tab with unsaved changes still asks. Untitled tabs are numbered as TextEdit numbers them.
- **Fast with big files.** TextKit 2 lays out only what is on screen; a 10 MB JSON file opens and is coloured in under 0.1 s, a 50 MB log in about 0.2 s on an M-series Mac.
- **Syntax colouring** for Swift, Python, JavaScript, TypeScript, JSON, YAML, Markdown, HTML (with embedded script and style), CSS, shell, C/C++/Objective-C and Ruby. The language comes from the extension, a `#!` line or, for pasted text, the content; the status bar overrides it.
- **Live preview** for Markdown and HTML, side by side (View › Show Preview, ⌥⌘P). JavaScript and network access in the preview are off by default and can be turned on per tab.
- **Themes:** System, Light, Dark, Tankard and Dracula. Every theme's text meets WCAG AA contrast. SF Mono by default; ⌘+ / ⌘− / ⌘0 zoom.
- **Find and replace** in the document with regular expressions (`$1` in replacements), match case and whole word; Replace All is one undo step. **Go to line** (⌘L, `42` or `42:7`), line numbers, current-line highlight, show invisibles, wrap lines.
- **Encodings and line endings:** UTF-8 (with or without BOM), UTF-16 LE/BE and Latin-1; LF, CRLF and CR. Detected on open, shown in the status bar, convertible on save; a file can be reopened in another encoding.
- **Files changed on disk** reload by themselves when the tab has no unsaved changes.
- **Editor tools:** Open Recent (⌥⌘1…9); text tools for sorting, removing duplicate lines, reversing, joining, trimming, changing case, JSON pretty-print/minify, XML pretty-print and Base64/URL encoding (each one undo step); **Find in Files** (⇧⌘F) with include and exclude globs; **Compare** two tabs side by side (⌥⌘C); **Follow File** for logs (⌥⌘T).
- **The `cedric` command:** `OwlInk.app/Contents/Resources/cedric` opens files in the running app (`cedric notes.md`, `cedric src/main.c:120`, `git log | cedric -`).
- **Cedric the owl** (View › Show Cedric the Owl, off by default): a small owl in the editor's corner that offers hints in a speech bubble: format one-line JSON, mixed indentation, trailing whitespace, a file changed on disk under your edits, long-unsaved work. Apply is one undo step; hints can be snoozed or silenced. It fades when the caret comes near.
- **Optional AI hints for the owl, off by default** (View › Cedric AI Settings…). Where the AI runs is your choice, and it is always local:
  - **Built-in:** OwlInk downloads a Qwen model (1.1–4.7 GB, pinned by URL and SHA-256, licence shown first) and runs it in the app with llama.cpp. Pause and resume, delete at any time. Nothing is sent anywhere; the only network traffic is the model download from Hugging Face.
  - **Apple Intelligence** on macOS 26 with Apple silicon, on-device only (never Private Cloud Compute).
  - **LM Studio or Ollama** on this Mac or another Mac on your local network. Public internet addresses are refused.
  - Only the visible text (up to 8 KB) is used, after a pause in typing, at most every 90 seconds by default, never on battery below 20 % or in Low Power Mode. AI suggestions are checked against the code and dropped when they are provably wrong.

### Known gaps
- **Find in Files** searches only (there is no Replace in Files). It skips files over 20 MB, and UTF-16 files without a byte-order mark are treated as binary and skipped, although the editor opens them. Files that are not UTF-8 or UTF-16 are read as Latin-1, so a regex for non-ASCII text won't match a file in another legacy encoding (Windows-1252, Shift JIS…). At most 10,000 results.
- **Compare** is a read-only snapshot of both tabs; past 4,000 differences the middle is shown as one changed block.
- **The Markdown preview** is not full CommonMark: no reference-style links, simplified emphasis rules, no lazy continuation lines.
- **A large unsaved file** is rewritten whole on each autosave. A file changed on disk while its tab has unsaved edits is only flagged by the owl's "Reload?" hint (when the owl is on).
- **Built-in AI on Intel Macs** runs on the CPU: expect 35–50 seconds per hint (measured on Apple silicon as a stand-in, not yet on an Intel Mac). A faster Mac on your network is the better choice there.
- **No macros, no printing, no automatic updates** yet. OwlInk is not sandboxed (an editor opens arbitrary files by path from the command line).

### For contributors
- SwiftPM and the Command Line Tools only: `Scripts/bundle-app.sh` builds `OwlInk.app` (`--universal` for both architectures), `Scripts/test.sh` runs the Swift Testing suite, and in-process checks drive the real app with NSEvents and snapshots (`Scripts/typing-check.sh`, `render-check.sh`, `owl-check.sh`, `ai-check.sh`, `tools-check.sh`, `session-check.sh`, `launch-check.sh`).
- Two portable modules (CedricCore, CedricAI: Foundation only, no AppKit) and the AppKit app. llama.cpp is a pinned SwiftPM binary target (release b12360, checksum-verified), copied into `Contents/Frameworks`.
- Releases: `Scripts/release.sh` builds universal, signs `llama.framework` and then the app with the hardened runtime and no entitlements, checks both carry the same Team ID, real-launches the signed app, notarizes, staples and zips; `.github/workflows/release.yml` runs it on a `v*` tag (a `-rcN` suffix makes a draft prerelease) and keeps Apple's notary log as a workflow artifact. `.github/workflows/tests.yml` runs the tests on pushes and pull requests with Swift 6.1. The version lives in one place, `CedricVersion.source`; the release refuses a build whose Info.plist, `CEDRIC_VERSION` or tag disagree with it.
