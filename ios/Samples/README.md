# Owlink for iPhone and iPad

A **simple text editor** for when you just want to look at a file.

- Syntax coloring for Swift, Python, JSON, YAML, Markdown and more
- Find and replace (`⌘F`, `⌥⌘F`)
- Cedric's hints, offline

> [!TIP]
> Ask Cedric uses Apple Intelligence on this device. Nothing goes to the cloud.

| Shortcut | Action |
|---|---|
| ⇧⌘P | Markdown preview |
| ⇧⌘K | Ask Cedric |

```swift
let owl = "Cedric"
print("Hello, \(owl)")
```
